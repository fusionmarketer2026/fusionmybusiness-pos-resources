# Fusion My Business POS Resources

Official public repository for educational resources and developer-facing information related to Fusion My Business.

Website: https://fusionmybusiness.com/en-gb/

## About

Fusion My Business provides point-of-sale (POS) and business software solutions. This repository is intended to host useful, accurate resources about POS technology, business workflows, and any integrations or developer materials that are officially documented.

## Repository Contents

- `docs/restaurant-pos-guide.md` — An introductory guide to restaurant POS systems.
- `docs/retail-pos-guide.md` — An introductory guide to retail POS systems.
- `docs/integrations.md` — Documentation covering verified Fusion My Business integrations.
- `resources/` — Supporting resources, diagrams, examples, and reference materials.
