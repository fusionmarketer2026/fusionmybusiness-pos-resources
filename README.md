# FusionMyBusiness POS Resources

Official public repository for educational resources and developer-facing information related to FusionMyBusiness.

Website: https://fusionmybusiness.com/en-gb/

## About

FusionMyBusiness provides point-of-sale (POS) and business software solutions. This repository is intended to host useful, accurate resources about POS technology, business workflows, and any integrations or developer materials that are officially documented.

## Repository contents

- `docs/restaurant-pos-guide.md` — introductory guide to restaurant POS systems.
- `docs/retail-pos-guide.md` — introductory guide to retail POS systems.
- `docs/integrations.md` — integration information. Only verified, currently supported integrations should be documented here.
- `resources/` — supporting diagrams, examples, and reference materials.
